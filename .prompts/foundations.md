# Foundations

The Orqlet workflow governs. This file restates its non-negotiables so that they are easy to find, and it does not define them.

- **No guessing.** An unknown becomes a question. It stays unknown until a person answers.
- **Four phases.** Research, design, plan, implementation. A person approves the design and the plan before implementation starts.
- **Required roles.** The roles that Orqlet names for each phase are required. A different agent may fill a role, the role stays.
- **Not run is not success.** A check that did not run is reported as not run.
