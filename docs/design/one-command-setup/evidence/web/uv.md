## Summary
- The official installation documentation provides POSIX shell and PowerShell standalone installers and version-specific installer URLs.
- uv can install a requested Python version and automatically download a missing interpreter.
- uv tools run in isolated environments; persistent installation uses uv tool install.
- The --python option selects an interpreter for a tool installation.
- Version constraints can pin tool packages. These documents do not establish an Orqlet package publication endpoint or verify this proposed combined installer on any OS.
