## Summary
- package.json declares Ponytail 5.3.3 and MIT licensing.
- Six skills are present: ponytail, ponytail-review, ponytail-audit, ponytail-debt, ponytail-gain and ponytail-help.
- The main skill prefers minimal complete changes, protects validation/security, and calls for a small test for non-trivial logic.
- Review and audit are reporting skills. The debt skill reports shortcuts and asks before persisting a ledger.
- Help also describes plugin lifecycle hooks, default-mode configuration and a Claude Code band. Those features have executable support outside the six Markdown skills.
- Gain displays an upstream benchmark, explicitly distinguishing it from measurements of the receiving repository.
- The skill front matter uses folded descriptions; the main skill also has argument-hint and license fields.
