### Three more habits

- When a request has more than one reasonable interpretation, name the interpretations and ask which one is meant; do not settle on one without saying so.
- When you notice dead code that your change did not touch, mention it and leave it in place; remove only what your own change left unused.
- For work with several steps outside a phase plan, write each step with the check that shows it worked, and run that check before the next step.

These three habits are written in Orqlet's words after the ideas of [andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills/tree/2c606141936f1eeef17fa3043a72095b4765b9c2).
