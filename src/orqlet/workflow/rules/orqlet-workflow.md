# Files that Orqlet writes

The files under `.orqlet/`, the client configuration folders (`.claude/`, `.cursor/`, `.agents/`, `.codex/`) and the managed block in `AGENTS.md` are generated by Orqlet.

- Do not edit them by hand. A protected file that differs from the render of the pinned Orqlet release fails review.
- To change one, change its source (the profile, the policy or the standards) and ask a maintainer to run `orqlet upgrade`.
- A file that Orqlet seeded once, such as `.prompts/`, belongs to the team. Edit it freely.
- `.mcp.json` was seeded by Orqlet and belongs to the team. Its entries named `orqlet-*` follow the declaration `.orqlet/integrations.yaml`, and a change to them arrives as a proposal. In a project that holds that declaration, no `orqlet-*` entry may hold a variable reference or a credential value, and the check runs only in such a project.
